# Apresentação acadêmica

## Descrição curta

O Demeter Dashboard é um protótipo em Python para análise exploratória de inventários florestais, com módulos de inventário, biomassa/carbono, qualidade de dados, modelagem inicial e clima.

## Justificativa

Dados florestais frequentemente são analisados em planilhas dispersas, com baixa padronização e pouca integração visual. O projeto busca transformar dados tabulares em indicadores interpretáveis, facilitando leitura, comparação entre talhões e identificação de inconsistências.

## Pontos técnicos demonstrados

- Estruturação de projeto Python
- Leitura de CSV e Excel
- Padronização automática de colunas
- Processamento com Pandas
- Visualização interativa com Plotly
- Interface web com Dash
- Tabelas interativas com Dash AG Grid
- Aplicação exploratória de machine learning
- Consulta de API climática externa
- Organização por módulos temáticos

## Limitações assumidas

- Estimativas de carbono são exploratórias
- O modelo não substitui equações locais ajustadas
- O módulo de potencial de carbono não gera créditos certificados
- O desempenho dos modelos depende da qualidade e quantidade dos dados
- A validação técnica exige campo, literatura e critérios metodológicos específicos
