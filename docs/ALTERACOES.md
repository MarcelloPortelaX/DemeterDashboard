# Alterações desta versão

- Revisão integral dos textos da interface para uma redação técnica e direta.
- Remoção de frases coloquiais, sarcásticas ou com aparência de texto automático.
- Renomeação da aba “IA” para “Modelagem”.
- Porta padrão alterada para 8051, evitando conflito com o ClaraJuris em 8050.
- Novo inicializador de dois cliques para Windows.
- Inclusão de configuração PyInstaller e GitHub Actions para criar uma distribuição portátil sem dependências instaladas no computador de destino.
