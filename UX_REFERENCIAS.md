# Referências de UX aplicadas

## IBM Carbon Design System

- hierarquia visual forte;
- poucos indicadores no primeiro nível;
- espaço como separador;
- consistência de layout entre gráficos;
- detalhes e interação conforme a necessidade.

Referência: https://carbondesignsystem.com/data-visualization/dashboards/

## Dashboard Design Patterns

- visão geral antes dos detalhes;
- abstração em camadas;
- exploração progressiva para conjuntos complexos.

Referência: https://dashboarddesignpatterns.github.io/

## Grafana

- o dashboard deve responder perguntas;
- gráficos focados;
- redução de carga cognitiva;
- navegação hierárquica e consistência.

Referência: https://grafana.com/docs/grafana/latest/visualizations/dashboards/build-dashboards/best-practices/

## Plotly

- gráficos responsivos;
- modo de interação consistente;
- exportação da imagem no tamanho renderizado.

Referência: https://plotly.com/python/configuration-options/
